# Security Policy

## Supported Versions

Security fixes are applied to the latest version on the `main` branch.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.
Use [GitHub's private vulnerability reporting](https://github.com/GodGMN/ghostmail-cli/security/advisories/new) to provide a description, steps to reproduce, impact, and any suggested remediation.

If private reporting is unavailable, contact the repository maintainers privately. Please allow a reasonable time for a response and coordinated fix before public disclosure.
